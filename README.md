# JavaScript Fundamentals – Internship Task

## About This Project
This repository contains JavaScript practice tasks assigned by **Stackly** as part of my internship training program.

The objective of this task is to understand and practise the fundamentals of JavaScript through hands-on coding exercises.

## Topics Covered
- **Primitive Data Types:** String, Number, Boolean, Undefined, and Null
- **Arrays:** Array creation, indexing, and length property
- **Objects:** Object creation, properties, and dot notation
- **Arithmetic Operators:** Addition, subtraction, multiplication, division, modulus, and exponentiation
- **Increment and Decrement Operators:** Pre-increment, post-increment, pre-decrement, and post-decrement

## Technologies Used
- JavaScript
- HTML
- Visual Studio Code

## Learning Outcomes
- Understanding JavaScript primitive data types.
- Working with arrays and objects.
- Using `typeof` and `length` properties.
- Performing arithmetic operations.
- Understanding pre-increment, post-increment, pre-decrement, and post-decrement.
